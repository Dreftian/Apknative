Instalar Android en el disco virtual

La ventana de la máquina virtual está abierta. Sigue estos 6 pasos una sola vez; luego Apknative iniciará directamente desde el disco sin requerir imagen ISO.

  1. Menú de inicio: Usa ↓ para seleccionar Installation - Install Android-x86 to harddisk y presiona Enter
  2. Elegir partición: Selecciona Create/Modify partitions; cuando pregunte si deseas usar GPT, elige No
  3. Particionador cfdisk: New → Primary → Presiona Enter en tamaño → Bootable → Write → escribe yes → Quit
  4. Formateo: Selecciona vda1 → al formatear elige ext4 → Yes
  5. Arranque y sistema: En Install GRUB elige Yes; en Install /system as read-write elige Yes
  6. Finalizar: Cuando alcance el 100%, haz clic abajo en «Completé la instalación» (Apknative reiniciará y tomará el control automáticamente)

Si luego indica que adb no está conectado: en la ventana de la máquina virtual presiona Ctrl+Alt+F1 para abrir la terminal y ejecuta setprop service.adb.tcp.port 5555, stop adbd, start adbd, y luego presiona Ctrl+Alt+F7 para regresar a la interfaz gráfica.

Modo automático (predeterminado, sin configuración requerida)
Detectando…
Memoria, núcleos de CPU, motor de renderizado, puertos y aceleración se seleccionan automáticamente. Si falla el arranque se reintenta automáticamente con parámetros seguros. Apknative utiliza un puerto de servicio adb dedicado (5044) (el adb de tu sistema usa 5037), por lo que adb devices en la consola no mostrará este dispositivo; esto es un aislamiento intencional. Para conectarte ejecuta $env:ANDROID_ADB_SERVER_PORT=5044 antes de adb. Nota: No intentes hacer adb connect manual al puerto 5555, ya que provocará una ventana emergente de depuración USB en la aplicación.
